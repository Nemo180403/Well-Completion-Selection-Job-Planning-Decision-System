# Well-Completion-Selection-Job-Planning-Decision-System
A field-experience-based decision-support framework for well completion and workover planning, covering completion selection, perforation, packer selection, bridge plug selection/setting/milling/retrieving, considering well conditions, and supporting engineering calculations. Slickline operations.
## Project objective 
This project converts field experience in well completion and workover operations into a structured decision-making workflow.
The system considers factors such as:
1. Well type (Exploratory and Development Well)
2. Well depth
3. No. of wells that have to be drilled in that particular block
4. Completion Configuration (liner or casing completion)
5. Packer requirements
6. Completion method
7. Workover requirements
8. Bridge plug requirements (type, setting procedure, retrievable or permanent)
## Project Workflow
Well type
1. Well characteristics
2. Completion Decision
3. Supporting Calculations
4. Completion/ Workover Job selection
## Basis of the Project
The decision framework is developed from field exposure to completion and workover operations.
## Note 
This is not a universal industry design criterion; it's all my experience gained during site work that defined some patterns to do operations with ease.
